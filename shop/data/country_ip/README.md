# Country IP data

The FI and SE IPv4/IPv6 CIDR lists are the aggregated country blocks published
by `ipverse/country-ip-blocks`, retrieved on 2026-08-20. The upstream data is
dedicated to the public domain under CC0 1.0.

Source: https://github.com/ipverse/country-ip-blocks

Only Finland and Sweden are stored because the storefront needs three routing
outcomes: FI, SE, and every other valid public address.
