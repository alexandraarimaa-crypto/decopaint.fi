## Правила

- Одна primary intent на landing page.
- Category отвечает на выбор; product — на конкретную покупку; guide — на вопрос.
- Не создавать страницы только ради городов без уникальной услуги/контента.
- Добавлять FAQ только из реальных вопросов; разметка должна совпадать с видимым текстом.
- Каннибализацию проверять по Search Console queries/pages.
